# Security Policy

## Supported Versions

Security fixes are provided for the latest version published to the Visual Studio Marketplace.
Users of older versions should upgrade before reporting an issue.

## Reporting a Vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability reporting:

https://github.com/ch3thanhs/ui-font-changer-vscode/security/advisories/new

Do not include vulnerability details in a public issue. If private reporting is unavailable,
open an issue containing no sensitive details and ask the maintainer to establish a private
communication channel.

Include the affected extension and VS Code versions, operating system, reproduction steps,
impact, and any suggested mitigation. Reports will be acknowledged and assessed as maintainer
availability permits.

Because this extension modifies files in the VS Code installation, stop using the affected
version until the report is assessed. If backup integrity is in doubt, repair or reinstall VS Code
instead of restoring from an untrusted backup.
